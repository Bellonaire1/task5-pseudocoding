# Pseudocode Standard

FUNCTION name

INPUTS:
- each input, its type, and what it means

OUTPUT:
- return type and meaning

SIDE EFFECTS:
- everything written/sent/changed outside the function
- or NONE

FAILS WHEN:
- every failure condition

Then:
- numbered steps
- one action per step
- plain English
- present tense
- no programming-language syntax
- explicit IF / OTHERWISE branches
- explicit loops
- external calls clearly marked
- state changes clearly marked
